✨ C'est quoi, ECOLIA H ?

Des guides pour réussir les exercices d'examen. Pour chaque notion, on te donne les formules, on t'explique quand les utiliser, on te montre les pièges classiques des exercices et la bonne méthode. Tu les télécharges une seule fois, puis tu les lis sans connexion, quand tu veux.

L'accès se fait par autorisation de ton identifiant. C'est un accès payant, pensé pour être simple et adapté à ta situation.

👀 Jette un œil à 3 guides

Touche un guide pour le lire ici, sans rien télécharger.

Les autres guides se débloquent une fois ton identifiant autorisé.

☰ Les 3 boutons du menu

Dans l'application, touche le bouton rond ☰ en bas à droite :

🆔 Mon IDTon identifiant sur cet appareil. C'est lui qui est autorisé. Tu peux y revérifier ton autorisation avec « 🔄 ».
📚 Voir les cours HLe catalogue des guides ECOLIA H, classé par niveau. Ils se téléchargent une fois ton ID autorisé.
📤 Partager ECOLIAPour faire connaître l'application autour de toi.

🔓 Comment accéder aux guides H ?

  1. Réponds aux 3 petites questions ci-dessous.
  2. Tu continues sur WhatsApp : ton message est déjà prêt, ton identifiant y est joint automatiquement.
  3. On te répond avec les conditions qui correspondent à ta situation.
  4. Une fois autorisé : ☰ → 🆔 Mon ID → 🔄 Revérifier, puis télécharge tes guides H.
